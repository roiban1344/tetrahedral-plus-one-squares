# 三角錐数+1型の平方数

[English](README.md)

**定理.** 自然数 $n$ について、$T(n)+1=\dfrac{n(n+1)(n+2)}{6}+1$ が平方数になるのは

$$n\in\{0,\ 5,\ 8,\ 22,\ 24,\ 63,\ 13775\}$$

のときであり、そのときに限る。

| $n$ | $T(n)$ | $T(n)+1$ |
|---:|---:|---:|
| 0 | 0 | $1^2$ |
| 5 | 35 | $6^2$ |
| 8 | 120 | $11^2$ |
| 22 | 2024 | $45^2$ |
| 24 | 2600 | $51^2$ |
| 63 | 43680 | $209^2$ |
| 13775 | 435730689800 | $660099^2$ |

証明は Lean 4 と Mathlib で形式化されている。

```lean
theorem Tetrahedral.tetrahedral_add_one_eq_sq_iff (n : ℕ) :
    (∃ m : ℕ, (n * (n + 1) * (n + 2) / 6 + 1 : ℚ) = m ^ 2) ↔
      n = 0 ∨ n = 5 ∨ n = 8 ∨ n = 22 ∨ n = 24 ∨ n = 63 ∨ n = 13775
```

この定理が依存する公理は、標準の `propext`, `Classical.choice`, `Quot.sound` だけである。

## 背景

$T(n)$ は三角錐数である（[OEIS A000292](https://oeis.org/A000292)）。
7つの $m$ は [OEIS A216269](https://oeis.org/A216269)「$k^2-1$ が三角錐数となる $k$」に登録されている。

$X=6n$, $Y=36m$ と置くと、方程式は楕円曲線

$$Y^2=X^3+18X^2+72X+1296$$

になる。Siegel の定理から整点は有限個だが、この定理は整点の大きさの上界を与えない。
そのため、整点をすべて求めるには通常、楕円対数の方法を使う。
この方法には、Mordell–Weil 群の基底と、楕円対数の1次形式の下界が必要である。

**ここでの証明は、楕円曲線の理論を使わない。**
使うのは、$\mathbb Z^4$ に乗法を入れた5つの環での計算、実数の不等式、整数の合同式だけである。
それ以外には、類数、単数定理、イデアルの一意分解、$p$ 進解析も使わない。

## 証明の概略

1. 方程式を5つの連立方程式 $n+3=dr^2,\ n^2+2=ey^2$ に分ける。$(d,e)$ は $(1,6)$, $(2,3)$, $(3,2)$, $(11,66)$, $(66,11)$ のいずれかである。
2. $n+y\sqrt e$ を、固定された元と平方の積で表す。Pell 方程式の一般論ではなく、解から、より小さい解を作る操作を繰り返す論法（「降下」）を使う。
3. 2つの式をまとめて、4次体 $L=\mathbb Q(\sqrt e,\theta)$ の元 $\xi$ で、2次体 $\mathbb Q(\sqrt e)$ への相対ノルムが $11=3^2+2$ であるものを作る。$\xi$ の第 $0$ 座標は $n+3$ である。
4. 既知の相対単数（相対ノルムが $1$ の元）$\rho$ の冪を掛けて、$\xi$ の実数値を一定の区間に移す。相対単数の全体は決定しない。
5. 区間に入った小さい元を、偶奇と判別式で決める。$\xi$ は小さい元 $\xi_0$ を使って $\xi_0\rho^m$ と書ける（$d=2$ で現れるもう1つの元は、法 $8$ と法 $16$ の合同式で除く）。
6. 指数 $m$ を、$2$ 進の一意性補題で決める。この補題は、$2$ の冪による整除を繰り返して示す。
7. 残る9つの元の第 $0$ 座標から $n$ を読む。そのうち2つは負の $n$ を与える。

詳しい議論は論文にある。

## 検証の方法

[elan](https://github.com/leanprover/elan) で Lean を入れてから、次を実行する。

```sh
cd lean
lake exe cache get   # コンパイル済みの Mathlib を取得する
lake build
lake env lean Check.lean
```

`Check.lean` は定理を改めて述べ、依存する公理を表示する。
`lean/Tetrahedral/NormEleven/` の証明の一部は、`scripts/` のスクリプトが生成したものである。
これらも通常の Lean の証明であり、カーネルが検査する。
CI はスクリプトを再実行し、生成されるファイルが変わらないことも確かめる。
