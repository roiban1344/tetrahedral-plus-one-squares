# Tetrahedral numbers plus one that are squares

[日本語](README.ja.md)

**Paper** · [English PDF](paper/en/tetrahedral-plus-one-squares-en.pdf) · [日本語 PDF](paper/ja/tetrahedral-plus-one-squares-ja.pdf) · [Released versions](../../releases)

**Theorem.** For a natural number $n$, the number $T(n)+1=\dfrac{n(n+1)(n+2)}{6}+1$ is a perfect square if and only if

$$n\in\{0,\ 5,\ 8,\ 22,\ 24,\ 63,\ 13775\}.$$

| $n$ | $T(n)$ | $T(n)+1$ |
|---:|---:|---:|
| 0 | 0 | $1^2$ |
| 5 | 35 | $6^2$ |
| 8 | 120 | $11^2$ |
| 22 | 2024 | $45^2$ |
| 24 | 2600 | $51^2$ |
| 63 | 43680 | $209^2$ |
| 13775 | 435730689800 | $660099^2$ |

The proof is formalized in Lean 4 with Mathlib.

```lean
theorem Tetrahedral.tetrahedral_add_one_eq_sq_iff (n : ℕ) :
    (∃ m : ℕ, (n * (n + 1) * (n + 2) / 6 + 1 : ℚ) = m ^ 2) ↔
      n = 0 ∨ n = 5 ∨ n = 8 ∨ n = 22 ∨ n = 24 ∨ n = 63 ∨ n = 13775
```

The theorem depends only on the standard axioms `propext`, `Classical.choice` and `Quot.sound`.

## Background

$T(n)$ is the tetrahedral number, [OEIS A000292](https://oeis.org/A000292).
The seven values of $m$ are listed in [OEIS A216269](https://oeis.org/A216269), "Numbers k such that k^2 - 1 is a tetrahedral number".

With $X=6n$ and $Y=36m$, the equation becomes the elliptic curve

$$Y^2=X^3+18X^2+72X+1296.$$

The solutions correspond to integral points with $X,Y\ge0$, $6\mid X$ and $36\mid Y$.
Siegel's theorem gives finiteness, and the elliptic logarithm method offers a way to compute all integral points.

The paper gives a proof using arithmetic in five explicit rings of rank 4 over $\mathbb Z$, real inequalities, and integer congruences.

## Reading the paper

1. Split the equation into five systems $n+3=dr^2,\ n^2+2=ey^2$, where $(d,e)$ is $(1,6)$, $(2,3)$, $(3,2)$, $(11,66)$ or $(66,11)$.
2. Write $n+y\sqrt e$ as a fixed element times a square, by a descent (an argument that repeatedly produces a smaller solution from a given one) instead of the general theory of Pell equations.
3. Combine the two equations into an element $\xi$ of a quartic field $L=\mathbb Q(\sqrt e,\theta)$ whose relative norm to $\mathbb Q(\sqrt e)$ is $11=3^2+2$. The first coordinate of $\xi$ is $n+3$.
4. Multiply $\xi$ by a power of a known relative unit $\rho$ (an element of relative norm 1) to move its real value into a fixed interval. The group of all relative units is not determined.
5. Determine the small element in that interval by parity and a discriminant. Then $\xi=\xi_0\rho^m$ for a small element $\xi_0$ (one more element that appears for $d=2$ is excluded by congruences modulo 8 and 16).
6. Determine the exponent $m$ by a 2-adic uniqueness lemma, proved by repeated divisibility by powers of 2.
7. Read $n$ from the first coordinate of the remaining nine elements; two give negative $n$.

The introduction connects these steps, §6 follows $n=22$ through the reduction to a small element, and Appendix A maps each stage of the proof to its Lean files.

## Checking the proof

Install Lean with [elan](https://github.com/leanprover/elan), then run:

```sh
cd lean
lake exe cache get   # download the compiled Mathlib
lake build
lake env lean Check.lean
```

`Check.lean` restates the theorem and prints its axioms.
Some proofs in `lean/Tetrahedral/NormEleven/` are generated by the scripts in `scripts/`.
They are ordinary Lean proofs that the kernel checks.
CI also reruns the scripts and checks that the generated files are unchanged.
